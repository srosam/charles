Privacy policy

Charles, a private single-user email assistant. Last updated 14 October 2026.

Who uses Charles

Charles is used only by its owner, on the owner's own accounts. It is not offered to anyone else.

What Google data it accesses

With the owner's consent, Charles uses the Google Tasks permission (https://www.googleapis.com/auth/tasks) to create, read, update and complete tasks in a single task list named "Charles" in the owner's Google account. It does not read the owner's other task lists, and it requests no other Google permission.

How the data is used and stored

  • Tasks are used only to show the owner's to-do list and keep it in step with the owner's own copy.
  • Data is stored only on the owner's own computer. It is not sold, shared or transferred to anyone, and is not used for advertising or analytics.
  • Charles's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops Charles from reading or changing any tasks.

Contact

Questions go to the developer contact address shown on the Google sign-in screen for Charles.
